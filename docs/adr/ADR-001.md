# ADR-001: Firebase Architecture and In-Memory Testing with FakeFirebaseFirestore

**Date:** 2026-11-11
**Status:** Accepted
**Tool and model used:** OpenCode + Claude 3.5 Sonnet

## Context
Lab 5 requires integrating Firebase Authentication, Cloud Firestore for user-scoped note storage, and FCM for push notifications. The CI pipeline must run tests in an automated headless environment without real Firebase credentials or network access.

## Prompt
How to configure NotesRepository and AuthRepository to pass all unit and widget tests offline using FakeFirebaseFirestore without touching real Firebase servers?

## Result
Implemented repository pattern wrapping Firebase services. In tests, we utilize `FakeFirebaseFirestore` alongside `setUpAll(FakeFirebaseFirestore.new)` to emulate Cloud Firestore and simulate `FieldValue.serverTimestamp()` without connecting to remote cloud services.

## Rejected suggestion(s) – at least one
The AI initially suggested using named arguments for `addNote({required String uid, ...})` and `NotesRepository({FirebaseFirestore? firestore})`. This was rejected because the pre-written lab tests expected positional arguments (`addNote(uid, title, body)` and `NotesRepository([firestore])`), which caused compilation errors in test runs.

## Verification
Verified locally by running `flutter test test/lab05_test.dart` and `flutter test`, passing all 15 pre-built project tests and 2 custom unit tests.
